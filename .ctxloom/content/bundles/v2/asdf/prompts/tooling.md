This bundle's content assumes the asdf version manager:

- asdf: Homebrew (`brew install asdf`) or the git install per
  https://asdf-vm.com/guide/getting-started.html (clone to ~/.asdf +
  shell init). Also install the plugins the project's .tool-versions
  names, then `asdf install`.
